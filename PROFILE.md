# Planomy Tax Data

A free, keyless open-data JSON API providing 2026 US retirement and tax figures — IRS contribution limits, income phase-outs, federal brackets, Social Security wage base and COLA, Medicare premiums and IRMAA, and RMD start age — sourced from IRS, SSA, and CMS. Served as a single static JSON file from the Planomy local-first personal-finance planner.

- **Provider:** https://planomy.net/data/

## APIs

- **Planomy Tax Data JSON** — A free, no-auth static JSON endpoint providing 2026 US tax and retirement data. Server-side consumable (not CORS-enabled). Includes a stable, additive field-level schema documented in prose. (`https://planomy.net`)

> The core interface is a single static JSON file at https://planomy.net/tax-data/2026.json (no key, no sign-up), not a multi-endpoint dynamic API. It is NOT CORS-enabled despite the submitted APIs.json claiming 'CORS-open' — it is intended for server-side consumption (curl/Node/Python/etc). A prose/field-level schema exists at https://planomy.net/data/#schema but there is no machine-readable OpenAPI/AsyncAPI/GraphQL/Postman contract. The apis.json at https://planomy.net/apis.json was referenced but could not be verified live. llms.txt is confirmed live. No MCP server (hosted or local) and no published agent skills were found. Data is public-domain, free to reuse.
